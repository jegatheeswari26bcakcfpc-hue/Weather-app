 Weatherly – Weather App

 ##Project Overview

Weatherly is a simple and attractive weather application UI designed to provide users with quick and clear weather information. The app allows users to check current weather conditions, view a 7-day forecast, and search for weather information in different locations.

 #Objective

The main objective of this project is to design a user-friendly weather application with a clean interface and easy navigation.

## Features

-  Current weather information
-  Location-based weather
-  Temperature details
-  Humidity information
-  Wind speed
-  Precipitation details
-  UV Index
-  7-Day weather forecast
-  Search for cities and locations
-  Recent locations
-  Popular cities
-  Easy bottom navigation
